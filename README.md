# Hotel Management Website

A modern and responsive hotel booking and management website built using PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript.

This project includes a user-friendly frontend along with an admin panel for managing rooms, facilities, bookings, and website settings.

---

# Features

## User Side
- Responsive modern UI
- Browse hotel rooms
- Room details page
- Facilities and services section
- Contact page with Google Maps integration
- Responsive design for all devices

## Admin Panel
- Admin authentication/login
- Add, update, and delete rooms
- Manage room images
- Manage facilities and features
- Website settings management
- Contact queries management

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/sujall-purohit/hotelwebsite.git
```

---

## 2. Move Project to XAMPP htdocs

```txt
C:\xampp\htdocs\
```

---

## 3. Start Apache & MySQL

Open XAMPP Control Panel and start:
- Apache
- MySQL

---

## 4. Import Database

1. Open phpMyAdmin
2. Create a new database
3. Import the SQL file

---

## 5. Run Project

Open browser:

```txt
http://localhost/hotelwebsite
```
